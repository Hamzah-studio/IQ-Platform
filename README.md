# منصة اختبار الذكاء التكيفي بالذكاء الاصطناعي 🧠

تطبيق ويب متكامل واحترافي لتقييم القدرات الذهنية وفق المعايير العالمية، مبني باستخدام `Streamlit` و `Google Gemini AI`.
يتميز التطبيق بالتكيف التلقائي (Adaptive Testing)، حيث تتغير الأسئلة وتتدرج في الصعوبة بناءً على عمر المستخدم وإجاباته السابقة.

## الميزات:
- **توليد ديناميكي للأسئلة:** الأسئلة لا تتكرر، وتُبنى في الوقت الفعلي عبر الذكاء الاصطناعي.
- **تغطية شاملة:** تشمل الاستدلال المنطقي، الرياضي، الفهم اللفظي، والقدرة المكانية.
- **لوحة تحكم وتحليل:** عرض نتائج تفصيلية باستخدام رسوم بيانية رادارية (Radar Charts).
- **سهولة النشر:** جاهز للرفع المباشر والمجاني على منصة Streamlit Community Cloud.
- **واجهة باللغة العربية (RTL):** تصميم أنيق ومخصص ليناسب المستخدم العربي.

## كيفية التشغيل المحلي (على جهازك):
1. تأكد من تثبيت Python.
2. افتح موجّه الأوامر (Terminal) واكتب:
   `pip install -r requirements.txt`
3. قم بتشغيل التطبيق عبر الأمر:
   `streamlit run app.py`

## كيفية النشر ليصبح متاحاً للجميع عبر رابط (مجانًا 100%):
1. قم برفع هذه الملفات الثلاثة (`app.py`, `requirements.txt`, `README.md`) إلى مستودع جديد على **GitHub**.
2. اذهب إلى موقع [Streamlit Share](https://share.streamlit.io/) وقم بتسجيل الدخول بحسابك في GitHub.
3. اضغط على `New App`، واختر المستودع الذي أنشأته، ثم اضغط `Deploy`.
4. انسخ الرابط الناتج وشاركه مع أي شخص للعمل على الهواتف وأجهزة اللابتوب بكفاءة عالية وبدون الحاجة لخادم.
