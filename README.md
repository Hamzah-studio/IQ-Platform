# منصة التقييم المعرفي الذكية (الإصدار الاحترافي v2) 🧠

تطبيق ويب حديث ومتطور لإجراء اختبارات الذكاء (IQ) التكيفية باللغة العربية مع واجهة مستخدم مظلمة وحجم كامل (Modern Dark Theme).

## التحديثات الجوهرية في هذا الإصدار:
1. **تسجيل الدخول عبر Google:** إتاحة الخيار الأكثر أماناً وسلاسة للتحقق من هوية المستخدم بنقرة واحدة بدون كلمات مرور.
2. **إلغاء طلب مفاتيح API من المستخدم تماماً:** لا يُطلب من المستخدم النهائى إدخال أي مفتاح API. يعمل التطبيق إما عبر المفتاح المركزي للخادم في `st.secrets` أو عبر محرك البنك المعرفي الذكي المدمج تلقائياً دون أي توقف.
3. **واجهة مستخدم فائقة الاحترافية (Custom CSS & RTL):** تصميم أنيق وجذاب مع إلغاء الشريط الجانبي المزعج وتحسين بطاقات الأسئلة والأزرار.
4. **دعم كافة أجهزة الهواتف والحواسب:** يتكيف خط وحجم الشاشة تلقائياً.

## كيفية النشر والتشغيل:
1. ارفع ملفات هذا المجلد إلى مستودعك على **GitHub**.
2. في **Streamlit Share** اضغط `Re-deploy` أو اضغط `Deploy` للمستودع الجديد.
3. (اختياري) يمكنك إضافة مفتاح الذكاء الاصطناعي المركزي الخاص بك داخل قسم `Secrets` في Streamlit عن طريق كتابة:
   ```toml
   AI_API_KEY = "مفتاحك_هنا"
   ```
